# Code of Conduct

AgySafe aims to be a practical, technical, and welcoming open-source project.

Be respectful, focus criticism on code and behavior rather than people, and assume good faith while still being precise about security and correctness.

Harassment, discrimination, personal attacks, threats, or deliberate publication of another person's credentials/private data are not acceptable.

Project maintainers may edit, hide, or remove contributions that expose secrets or violate these expectations.
